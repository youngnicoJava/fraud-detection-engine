# Portfolio demo assets

Suggested screenshots to capture after running the analyst console:

- `assessment-queue.png` — filtered assessment table and PASS/REVIEW/BLOCK distribution.
- `assessment-detail.png` — score, risk level, reason codes, signals and input context.
- `case-review.png` — case history, analyst actions and final disposition.

Screenshots are intentionally not committed until captured from a running application so the repository does not imply a live session that was never verified.
